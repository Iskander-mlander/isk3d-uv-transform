# Changelog

## 1.4.1

- Corregido el panel vacío en objetos con un atributo base UV antiguo: la captura de base ya no se ejecuta durante el dibujado del panel.
- La base UV se captura al mover el primer control o con **Fijar UV actuales**.

## 1.4.0

- Añadidas proyecciones **Cube**, **Cylinder**, **Sphere**, **Unwrap**, **Smart UV Project**, **Lightmap Pack**, **Project from View**, **Project from View (Bounds)** y **Follow Active Quads**.
- Añadido botón para entrar/salir de **Edit Mode** desde el panel.
- Corregido el primer cambio de slider, que se perdía al capturar la base UV.
- Añadidos ajustes de proyección: eje, ajuste a 0–1, ángulo/margen de Smart UV y método/margen de Unwrap.

## 1.3.1

- Añadido desplegable de atajos para seleccionar caras.

## 1.3.0

- Añadido ámbito **Objeto completo / Caras seleccionadas**.
- `Reset UV` respeta el ámbito seleccionado.
- Validación de la base UV para evitar colapsar las UV a un punto.
- Añadido **Fijar UV actuales como base**.

## 1.2.0

- Addon convertido en herramienta genérica de transformación UV.
- Controles numéricos de desplazamiento y escala.
- Base UV guardada sin crear capas UV extra.
